# ZeroFRANK: руководство по сборке и эксплуатации

<p align="center">
  <img src="./boards/3d/zerofrank-iso.png" alt="3D-рендер ZeroFRANK" width="640">
</p>

ZeroFRANK — это минималистичный FRANK: RP2350A, распаянный на крошечной плате с выходом HDMI, двумя портами USB-C и слотом MicroSD. Несмотря на свои размеры, плата несет на борту флеш-память W25Q128 (16 MB) и 8 MB PSRAM, а также аудио по интерфейсу I²S через ЦАП TDA1387 — поэтому прошивки, требующие PSRAM, работают без каких-либо дополнительных модулей. Нет VGA, нет PS/2, нет портов для геймпада, нет WiFi — клавиатуры, мыши и геймпады подключаются через USB. Это самый компактный способ запустить полноценный FRANK-класса RP2350A с PSRAM и видео по HDMI.

Один порт USB-C несет нативный USB от RP2350; второй — это host-порт PIO-USB для устройств ввода. Звук выводится через встроенный I²S-ЦАП TDA1387 на гнездо 3.5 мм. Дополняют плату 3-контактный порт SWD JST-SH, а также кнопки BOOT и RESET.

- **Размер платы:** 65 × 25 mm
- **Вычисления:** RP2350A QFN-60, распаян на плате
- **KiCad-проект:** [`hardware/zerofrank/`](../hardware/zerofrank)
- **Gerber-файлы:** [`hardware/zerofrank/gerbers/`](../hardware/zerofrank/gerbers/)
- **BOM, схемы PDF, сборочный чертеж:** [`hardware/zerofrank/docs/`](../hardware/zerofrank/docs/)

## Состав платы

| Подсистема | Компонент(ы) | Назначение |
|------------|--------------|------------|
| Вычисления | RP2350A QFN-60 | Распаян непосредственно на плате. |
| Флеш-память | W25Q128JVS | SPI-флеш 16 MB. |
| PSRAM | ESP-PSRAM | 8 MB PSRAM. |
| Видео | HDMI Type A | Выход HDMI (только HDMI — без VGA, без композита). |
| USB (нативный) | USB Type-C | Нативный USB RP2350. |
| USB host | USB Type-C (PIO-USB) | Клавиатуры, мыши и геймпады через USB. |
| Аудиовыход | TDA1387T + гнездо 3.5 мм | Линейный аудиовыход по I²S. |
| Накопитель | Слот MicroSD | ROM-образы, WAD-файлы, образы дисков. |
| Отладка | 3-контактный SWD JST-SH | Отладка по Serial-Wire. |
| Кнопки | BOOT, RESET | Bootsel + сброс. |
| Гребенки | UART | Отладочный последовательный порт. |

## Спецификация (BOM, обзор)

Полный точный BOM генерируется из KiCad-проекта и публикуется в файле
[`hardware/zerofrank/docs/<rev>/bom.html`](../hardware/zerofrank/docs/). Ключевые компоненты —
это RP2350A QFN-60, флеш W25Q128JVS (16 MB), 8 MB PSRAM, I²S-ЦАП TDA1387T, LDO-стабилизатор и
разъемы HDMI / USB-C / MicroSD.

## Замечания по сборке

- RP2350A в корпусе QFN-60 — используйте горячий воздух или нагревательный стол. Сначала
  припаяйте его, флеш-память и PSRAM, затем LDO-стабилизатор и пассивы, после чего разъемы.
- Преобладают пассивы 0603; пригодится микроскоп или лупа.

## Первый запуск

1. Удерживая BOOT, подключите нативный USB-C, отпустите кнопку и скопируйте файл `.uf2` на
   появившийся накопитель (либо используйте `picotool load`).
2. Подключите HDMI-дисплей.
3. Подключите USB-клавиатуру / мышь / геймпад к host-порту PIO-USB.
4. Установите карту MicroSD с ROM-образами или образами дисков.

## Совместимость прошивок

На ZeroFRANK 16 MB флеш-памяти и 8 MB PSRAM на борту, поэтому прошивки, требующие PSRAM
(frank-os, frank-386, frank-snes, frank-genesis, frank-quest, порты id Tech 1 и так далее),
работают без каких-либо дополнительных модулей. Единственные ограничения касаются ввода-вывода:
видео только по HDMI и ввод только по USB (нет VGA, PS/2, геймпада DB9 или WiFi).

## Поиск и устранение неисправностей

- **Нет изображения:** убедитесь, что прошивка рассчитана на HDMI (на ZeroFRANK нет VGA) и
  что RP2350A, флеш-память и PSRAM пропаяны качественно.
- **Нет ввода через USB:** устройства ввода подключаются к порту Type-C **PIO-USB**, а не к
  нативному.
- **Нет звука:** звук выводится по I²S через TDA1387 — проверьте ЦАП и разводку гнезда 3.5 мм.
