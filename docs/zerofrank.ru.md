# ZeroFRANK: руководство по сборке и эксплуатации

<p align="center">
  <img src="./boards/3d/zerofrank-iso.png" alt="ZeroFRANK 3D render" width="640">
</p>

ZeroFRANK — это минималистичная версия FRANK: RP2350A, распаянный напрямую на крошечной плате, с выходом HDMI, двумя портами USB-C и слотом MicroSD. Нет ни VGA, ни PS/2, ни портов для геймпадов, ни Wi-Fi — клавиатуры, мыши и геймпады подключаются через USB. Это самый компактный способ запустить RP2350A класса FRANK с видеовыходом HDMI.

Один USB-C обслуживает нативный USB RP2350; второй — это host-порт PIO-USB для устройств ввода. Звук выводится через распаянный на плате ЦАП TDA1387 на гнездо 3.5 мм. Дополняют плату 3-контактный порт SWD JST-SH, а также кнопки BOOT и RESET.

- **Размер платы:** 65 × 25 mm
- **Вычислитель:** RP2350A QFN-60, распаян на плате
- **KiCad-проект:** [`hardware/zerofrank/`](../hardware/zerofrank)
- **Gerber-файлы:** [`hardware/zerofrank/gerbers/`](../hardware/zerofrank/gerbers/)
- **BOM, схемы PDF, сборочный чертеж:** [`hardware/zerofrank/docs/`](../hardware/zerofrank/docs/)

> **Недавно перенесено из [frank-lab](https://github.com/rh1tech/frank-lab).** На ZeroFRANK
> нет распаянной PSRAM, поэтому прошивки, требующие 8 МБ PSRAM, на ней не запустятся.
> Изучите схему и BOM перед заказом печатной платы.

## Состав платы

| Подсистема | Компонент(ы) | Назначение |
|------------|--------------|------------|
| Вычислитель | RP2350A QFN-60 | Распаян напрямую на плате |
| Флеш-память | QSPI-флеш (SOIC-8) | Хранение прошивки |
| Видео | HDMI Type A | Выход HDMI (только HDMI — без VGA, без композита) |
| USB (нативный) | USB Type-C | Нативный USB RP2350 |
| USB host | USB Type-C (PIO-USB) | Клавиатуры, мыши и геймпады через USB |
| Аудиовыход | TDA1387T + гнездо 3.5 мм | Линейный аудиовыход (интерфейс I²S) |
| Накопитель | Слот MicroSD | ROM-образы, WAD-файлы, образы дисков |
| Отладка | 3-контактный SWD JST-SH | Отладка по Serial-Wire |
| Кнопки | BOOT, RESET | Bootsel + сброс |
| Гребенки | UART | Отладочный последовательный порт |

## Спецификация (BOM)

Полный точный BOM генерируется из KiCad-проекта и публикуется в файле
[`hardware/zerofrank/docs/<rev>/bom.html`](../hardware/zerofrank/docs/). Ключевые компоненты:
RP2350A QFN-60, QSPI-флеш, ЦАП TDA1387T, LDO-стабилизатор и разъемы HDMI / USB-C / MicroSD.

## Замечания по сборке

- RP2350A в корпусе QFN-60 — используйте горячий воздух или нагревательный стол. Сначала
  припаяйте его и флеш-память, затем LDO-стабилизатор и пассивы, после чего разъемы.
- Преобладают пассивы 0402/0603; пригодится микроскоп или лупа.
- Поскольку PSRAM отсутствует, используйте только прошивки, работающие из SRAM/флеш-памяти
  (см. примечания ниже).

## Первый запуск

1. Удерживая BOOT, подключите нативный USB-C, отпустите кнопку и скопируйте файл `.uf2` на
   появившийся накопитель (либо используйте `picotool load`).
2. Подключите HDMI-дисплей.
3. Подключите USB-клавиатуру / мышь / геймпад к host-порту PIO-USB.
4. Установите карту MicroSD с ROM-образами или образами дисков.

## Совместимость прошивок

На ZeroFRANK **нет распаянной PSRAM**. Прошивки, требующие 8 МБ PSRAM (frank-os, frank-386,
frank-snes, frank-genesis, frank-quest, порты id Tech 1 и так далее), не запустятся. Подходят
прошивки, не требующие PSRAM, — такие как [frank-kickstart](https://github.com/rh1tech/frank-kickstart),
[frank-digger](https://github.com/rh1tech/frank-digger) и многие оригинальные ядра ZX Spectrum
для Murmulator.

## Поиск и устранение неисправностей

- **Нет изображения:** убедитесь, что прошивка рассчитана на HDMI (на ZeroFRANK нет VGA) и
  что RP2350A и флеш-память пропаяны качественно.
- **Нет ввода через USB:** устройства ввода подключаются к порту Type-C **PIO-USB**, а не к
  нативному.
- **Прошивка не загружается:** убедитесь, что она не требует PSRAM — на ZeroFRANK ее нет.
