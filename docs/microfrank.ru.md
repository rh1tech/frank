# MicroFRANK: руководство по сборке и эксплуатации

<p align="center">
  <img src="./boards/3d/microfrank-iso.png" alt="3D-рендер MicroFRANK" width="640">
</p>

MicroFRANK — наименьшая плата семейства. Уменьшенный вариант FRANK с RP2350A, флеш-памятью, PSRAM и USB host, распаянными непосредственно на плате. На плате отсутствуют VGA, аппаратный PS/2, DB9 для геймпадов и сокет под ESP-01S. Подключение клавиатур, мышей и геймпадов выполняется по USB. Питание подается через USB-C.

При необходимости VGA, композита, DB9 или Wi-Fi следует выбирать FRANK или MiniFRANK. MicroFRANK ориентирован на сборки, в которых критичны габариты, а HDMI и USB достаточны.

- **Размер платы:** 32 × 74 мм
- **KiCad-проект:** [`hardware/microfrank/`](../hardware/microfrank)
- **Gerber-файлы:** [`hardware/microfrank/gerbers/`](../hardware/microfrank/gerbers/)
- **BOM, схемы PDF, сборочный чертеж:** [`hardware/microfrank/docs/`](../hardware/microfrank/docs/)

MicroFRANK — самая плотная по компоновке плата семейства. Для пайки требуется микроскоп или качественная лупа и инструмент горячего воздуха.

1. **RP2350A QFN-60.** Нанесите паяльную пасту, установите микросхему пинцетом, выполните пайку горячим воздухом при температуре около 280 °C. Под увеличением проверьте каждый вывод.
2. **Флеш-память W25Q128JVS, ESP-PSRAM64H, кварцевый резонатор 12 МГц.** Соблюдайте маркировку вывода 1.
3. **Конденсаторы развязки 0603** вокруг RP2350A, флеш-памяти и PSRAM.
4. **Остальные резисторы и конденсаторы 0603.**
5. **Поверхностные ИС:**
   - TS3USB221RSER
   - USBLC6-2SC6
   - Контроллер хаба MW7211A
   - LM358
   - ME6211C33M5 LDO
6. **Силовой дроссель 3.3 мкГн и диод Шоттки.**
7. **Тактовая кнопка (RP Boot).**
8. **Переключатели (SK12D07VG3NS, MSK12C02).**
9. **Выводные и SMT-разъемы:**
   - HDMI Type A
   - PJ-320D 3.5 мм
   - Слот microSD (Molex 0475710001)
   - Сдвоенный USB Type-A
   - USB Type-C (питание)
10. **TDA1387T** (ЦАП в корпусе SO-8).
11. **Крепеж** при установке платы в корпус.

Контрольные точки:

- После шагов 1–2: прозвонка шины USB-питания относительно общего провода.
- После шага 5: подача питания по USB. При удержании RP Boot во время подключения RP2350A должен определиться как накопитель `RPI-RP2`.
- После шага 9: проверка HDMI на заведомо рабочей UF2-прошивке.

## Первый запуск

1. Подайте 5 В через разъем USB-C.
2. Подключите дисплей к видеовыходу HDMI (на этой плате это единственный видеовыход).
3. Подключите USB-клавиатуру к сдвоенному разъему USB Type-A. Аппаратный PS/2 на данной плате отсутствует — клавиатура подключается только по USB.
4. Установите SD-карту FAT32 с ROM-образами и образами дисков. Карта используется прошивкой во время работы — запись прошивки с SD-карты не выполняется.
5. Включите питание.

Прошивка выполняется через USB-C. Удерживайте кнопку **RP Boot** при подаче питания (или при нажатии Reset, в зависимости от варианта прошивки). RP2350A определится как накопитель `RPI-RP2`; скопируйте на него файл `.uf2`.

## Ограничения MicroFRANK

Особенности, которые следует учитывать при выборе платы:

- VGA-выход отсутствует. Только HDMI.
- Композитный видеовыход отсутствует.
- Аппаратный PS/2 отсутствует. Клавиатуры и мыши подключаются только по USB.
- DB9 для геймпадов отсутствует. Геймпады подключаются только по USB.
- Сокет ESP-01S отсутствует, Wi-Fi не предусмотрен.
- Усилитель для динамика отсутствует. Только линейный аудиовыход.
- Кассетный вход отсутствует.

Если прошивке необходим какой-либо из этих узлов, следует выбирать MiniFRANK или FRANK.

## Поиск и устранение неисправностей

| Признак | Возможная причина |
|---------|-------------------|
| Плата не определяется как USB-накопитель | Дефект пайки QFN, в первую очередь — теплоотводящей площадки. Добавьте флюс и повторите пайку горячим воздухом. |
| Плата работает несколько секунд и зависает | Дефект пайки PSRAM. |
| Изображение HDMI отсутствует | Прошивка под другую плату либо короткое замыкание сигнальных линий HDMI. |
| Искажение звука | Шум на шине питания LM358; проверьте конденсаторы развязки. |
| USB-устройства не определяются | Отсутствие контакта на хабе MW7211A или коммутаторе TS3USB221; повторная пайка. |
