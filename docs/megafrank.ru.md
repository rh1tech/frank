# MegaFRANK: руководство по сборке и эксплуатации

<p align="center">
  <img src="./boards/3d/megafrank-iso.png" alt="MegaFRANK 3D render" width="640">
</p>

MegaFRANK — это максимальная версия FRANK: все видеовыходы, все аудиотракты и распаянный на плате звуковой модуль TurboSound на одной полноразмерной печатной плате. В качестве вычислителя используется Pimoroni PGA2350 (модуль на RP2350B со встроенной флеш-памятью и 8 МБ PSRAM), поэтому все прошивки, требующие PSRAM, работают без дополнительных модулей. Если вам нужна одна плата, которая умеет буквально все, на что способен FRANK, — это она.

Плата несет полный набор выходов — HDMI, VGA, тракты композитного видео/TFT, аппаратный PS/2, два порта DB9 для геймпадов — плюс распаянный на плате сдвоенный YM2149 TurboSound, часы реального времени DS3231, кремниевый серийный номер DS2401, Wi-Fi через ESP-01S, слот MicroSD и два входа питания. Раскладка GPIO в формате M2 означает, что на плате работает любая прошивка, собранная под M2.

- **Размер платы:** 149.9 × 99.5 mm (полный размер)
- **Вычислитель:** Pimoroni PGA2350 (модуль на RP2350B, встроенная флеш-память + 8 МБ PSRAM)
- **KiCad-проект:** [`hardware/megafrank/`](../hardware/megafrank)
- **Gerber-файлы:** [`hardware/megafrank/gerbers/`](../hardware/megafrank/gerbers/)
- **BOM, схемы PDF, сборочный чертеж:** [`hardware/megafrank/docs/`](../hardware/megafrank/docs/)

> **Недавно перенесено из [frank-lab](https://github.com/rh1tech/frank-lab).** MegaFRANK —
> самая большая и сложная плата семейства FRANK. Изучите схему и BOM перед заказом
> печатной платы.

## Состав платы

| Подсистема | Компонент(ы) | Назначение |
|------------|--------------|------------|
| Вычислитель | Pimoroni PGA2350 (RP2350B) | Установка в сокет модуля. Встроенная флеш-память + 8 МБ PSRAM. |
| Звуковой модуль | 2 × YM2149 / AY-3-8910 (сокеты DIP-40) | TurboSound на плате. Установка в сокеты позволяет ставить оригинальные или NOS-микросхемы. |
| Тактирование звука | Кварцевый резонатор HC49-S + 74HCT74 | Источник тактирования и делитель для звуковых микросхем |
| Звуковой ЦАП | TDA1387T | Линейный аудиовыход (интерфейс I²S) |
| Усилитель динамика | PAM8403 | Усилитель для динамика на плате |
| Часы реального времени | DS3231 | RTC с резервным питанием (батарейка-таблетка) |
| Кремниевый серийный номер | DS2401 | Уникальный идентификатор 1-Wire |
| Видео | HDMI Type A, VGA DE-15 | Выходы HDMI + VGA |
| Клавиатура / мышь | PS/2 (mini-DIN-6) | Аппаратный PS/2 |
| Геймпад | 2 × DB9 | Два порта для контроллеров в стиле Famicom |
| USB host | Сдвоенный USB Type-A + хаб + мультиплексор | Сдвоенный host-порт USB для клавиатур, мышей и геймпадов |
| Питание / данные USB | USB Type-C | Вход 5 V / данные |
| Сеть | Сокет под ESP-01S | Опциональный Wi-Fi (прошивка [frank-netcard](https://github.com/rh1tech/frank-netcard)) |
| Накопитель | Слот MicroSD | ROM-образы, WAD-файлы, образы дисков |
| Аудиовыход / кассета | 2 × гнезда 3.5 мм | Линейный аудиовыход + кассетный вход |
| Питание | 2 × гнездо DC | Два входа питания |
| Кнопки | RP Reset, BOOT, ESP Reset | Кнопки сброса / bootsel |
| Раскладка | M2 GPIO | На плате работает любая прошивка, собранная под M2 |

## Замечания по сборке

- Сначала припаяйте SMD-компоненты (ЦАП, усилитель, RTC, хаб/мультиплексор, пассивы),
  двигаясь от самых мелких корпусов к крупным, затем установите выводные разъемы и в
  последнюю очередь — сокеты DIP-40 под звуковые микросхемы.
- Звуковые микросхемы устанавливаются в сокеты DIP-40 — **не** припаивайте YM2149/AY-3-8910
  напрямую; ставьте их в сокеты, чтобы можно было менять микросхемы.
- PGA2350 устанавливается в свой сокет модуля; устанавливайте его после того, как остальная
  часть платы будет собрана.
- Устанавливайте батарейку-таблетку DS3231 только после того, как убедитесь, что остальная
  часть платы включается.

## Первый запуск

1. Установите модуль PGA2350 и (опционально) звуковые микросхемы и ESP-01S.
2. Подайте питание на плату через один из разъемов DC.
3. Удерживая кнопку BOOT на модуле RP, подключите USB-C, отпустите кнопку и скопируйте файл
   `.uf2` на появившийся накопитель (либо используйте `picotool load`). [frank-kickstart](https://github.com/rh1tech/frank-kickstart)
   — хороший вариант для первой прошивки: это загрузчик прошивок с SD-карты.
4. Подключите дисплей (HDMI или VGA), клавиатуру (PS/2 или USB) и геймпад, после чего
   установите SD-карту с ROM-образами.

## Поиск и устранение неисправностей

- **Нет изображения:** убедитесь, что PGA2350 полностью установлен, а прошивка соответствует
  вашему выходу (HDMI или VGA). Большинство прошивок определяют выход автоматически; в
  некоторых есть переключатель на этапе сборки.
- **Нет звука от TurboSound:** проверьте правильность ориентации YM2149/AY-3-8910 в сокетах
  и наличие кварцевого резонатора тактирования звука.
- **RTC не сохраняет время:** установите свежую батарейку-таблетку и проверьте ориентацию
  DS3231.
- **Прошивка с Wi-Fi не видит ESP:** ESP-01S опционален — устанавливайте его только для
  прошивок с поддержкой Wi-Fi, таких как [frank-manul](https://github.com/rh1tech/frank-manul)
  или [frank-netcard](https://github.com/rh1tech/frank-netcard).
